## 📦 部署说明

### 环境要求
- Node.js >= 18
- PM2 >= 5
- HashiCorp Vault >= 1.13
- 企微自建应用（AgentID、Token、EncodingAESKey）

### 快速部署
```bash
git clone https://github.com/haojia258/wecom-openclaw.git
cd wecom-openclaw
git checkout develop
npm install
cp .env.example .env
# 填写企微配置 + Vault AppRole
pm2 start apps/wecom-adapter/src/index.js --name wecom-adapter
pm2 start apps/ads-worker/src/index.js --name ads-worker
```

### 升级到 v1.1（Vault 集成）
```bash
git pull origin develop
# 1. 部署 Vault 并初始化 AppRole
# 2. 写入 kv/wecom/prod/* 密钥
# 3. 更新 .env：注释掉明文 WECOM_CORP_ID / WECOM_SECRET
# 4. pm2 reload wecom-adapter
```
