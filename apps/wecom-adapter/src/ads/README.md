# 推广投流分析模块 (Ads Analysis)

## 职责
根据广告投流数据，自动生成实操分析报告，包括 ROI、消耗、转化率、点击率、GMV、放量风险与明确操作建议。

## 输入
- `logs/ads/ads-report_latest.json`（标准化后使用）

## 输出
中文报告，≤600字，结构：
1. 今日投流摘要
2. ROI分析
3. 放量/停投建议
4. SKU推荐
5. 风险提示
6. 综合评分
7. 今日最优先动作

## 规则与评分
- 规则集中在 `ads-rules.js`，可调参
- 评分模型在 `ads-score-model.js`，输出0-100分维度

## 完全规则驱动，无外部依赖，保证 100% 可运行
