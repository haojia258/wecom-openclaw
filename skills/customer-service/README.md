# Skill: 客服

## 概述

企业微信消息接收与自动回复，基础关键词路由。

## MVP 阶段功能

- 接收企业微信文本消息
- 关键词匹配路由到对应处理器
- 返回格式化文本回复

## 支持的关键词

| 关键词 | 响应 |
|--------|------|
| 今日订单 | 查询今日订单数据 |
| 今日GMV | 查询今日 GMV |
| 生成日报 | 触发日报生成 |
| 检查抖店登录 | 检查浏览器登录状态 |
| 其他 | 显示帮助菜单 |

## 架构

```
企业微信 → wecom-adapter → OpenClaw/Mock → 企业微信回复
```

## 暂不支持（MVP 外）

- 自动客服（商品咨询回复）
- 买家消息处理
- 多轮对话上下文管理
