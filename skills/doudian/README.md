# Skill: 抖店运营

## 概述

OpenClaw 抖音小店运营技能，负责查询订单、GMV、商品等核心数据。

## MVP 阶段支持的指令

| 指令 | 说明 | 状态 |
|------|------|------|
| 今日订单 | 查询今日订单概况 | ✅ Mock |
| 今日GMV | 查询今日 GMV 数据 | ✅ Mock |
| 检查抖店登录 | 检查 Playwright 登录状态 | ✅ Mock |

## 数据来源

MVP 阶段使用 Mock 数据。后续对接：

- 抖店开放平台 API（需申请权限）
- Playwright 抓取（备用方案）
