# Skill: 日报生成

## 概述

自动生成抖店运营日报并推送到企业微信。

## 日报格式

```
【抖店日报】
日期：YYYY/MM/DD
GMV：¥ XX,XXX
订单数：XXX
退款数：XX
待发货：XX
核心建议：
1. ...
2. ...
```

## 触发方式

1. **定时触发**：每天 21:00 自动生成（可配置 `REPORT_CRON`）
2. **手动触发**：
   - 企业微信发送「生成日报」
   - 调用 `POST /report/generate` 接口

## 推送渠道

- 企业微信群机器人（配置 `WECOM_WEBHOOK_URL`）
- 后续支持：邮件、飞书

## MVP 限制

- 当前使用 Mock 数据
- 后续接入真实抖店数据后，需更新 `getMockData()` 函数
